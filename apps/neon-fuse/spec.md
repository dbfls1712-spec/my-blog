# 네온 퓨즈 (Neon Fuse) — 계획서

## 1. 개요
- 앱 이름: 네온 퓨즈 / Neon Fuse
- 폴더: `apps/neon-fuse/`
- 한 줄 소개: 같은 빛의 칩을 밀어 붙여 더 밝은 빛으로 융합하는 4×4 퍼즐.
- 콘셉트: 격자는 어두운 "회로 기판", 타일은 모서리가 잘린 "발광 칩". 같은 값의 칩이 부딪히면 하나로 융합되어 다음 단계의 빛이 됩니다. 단계가 오를수록 테두리만 빛나던 칩이 점점 색이 바뀌고, 고단계에서는 칩 전체가 빛으로 채워집니다.
- 타일 값은 숫자(2, 4, 8 …)로 표시하되, 단계(Lv)를 시각 표현의 기준으로 삼습니다(Lv = log2(값)).

## 2. 게임 규칙
- 시작: 빈 4×4 격자에 타일 2개를 무작위 빈 칸에 놓습니다.
- 새 타일: 값 2(확률 90%) 또는 4(확률 10%). 실제로 무언가 움직였거나 합쳐졌을 때만 1개 생성합니다(아무 변화 없는 방향 입력은 무시).
- 밀기: 모든 타일이 선택한 방향 끝까지 이동합니다.
- 합치기: 이동 방향 앞쪽부터 처리합니다. 같은 값 두 개가 만나면 값 2배인 타일 하나가 됩니다. 한 번 밀 때 이미 합쳐진 타일은 다시 합쳐지지 않습니다(예: `[2,2,2,2]` → `[4,4,0,0]`, `[4,4,8,0]` → `[8,8,0,0]`).
- 점수: 합쳐서 생긴 타일 값만큼 더합니다(2+2 → +4).
- 최고 점수: 현재 점수가 최고 점수를 넘으면 즉시 갱신·저장합니다.
- 게임 오버: 빈 칸이 없고, 가로·세로로 이웃한 같은 값이 하나도 없을 때. 오버레이로 안내하고 "다시 하기" 버튼을 보여 줍니다.
- 목표 숫자: 정해진 승리 조건 없음(끝없는 모드). 대신 이번 판에서 처음 도달한 단계가 Lv 7(값 128) 이상이면 "새 빛 단계 도달: Lv N"을 짧은 토스트로 보여 주고 `aria-live`로 알립니다. 게임은 멈추지 않습니다.

- 고유 연출
  - 기판: `--bg-elev` 바탕, 1px 회로선(빈 칸은 점선 테두리), 격자 네 모서리에 L자 브래킷 장식(cyan). 그림자 빛번짐 없음.

## 4. 조작과 접근성
- 키보드: ←↑→↓ 및 W/A/S/D(대소문자 무관). 게임 키 입력 시 `preventDefault`로 페이지 스크롤 방지. 오버레이가 열려 있으면 이동 입력 무시. 입력이 버튼·링크에 포커스된 상태의 Enter/Space는 기본 동작 유지.
- 스와이프: 격자 영역에서 Pointer Events(`pointerdown`/`pointerup`, `pointerType`이 touch·pen·mouse 모두) 사용. 이동 거리 ≥ 30px이고 주 축 거리 > 다른 축 거리 × 1.2일 때 그 방향으로 밉니다. 격자에 `touch-action: none`, 바디에 `overscroll-behavior: none`을 줘 스와이프 중 스크롤·당겨서 새로고침 방지.
- 연속 입력: 이동 애니메이션 중(약 120ms) 들어온 입력은 버리지 않고 즉시 다음 상태로 처리(상태는 동기적으로 갱신, 화면만 따라감).
- 접근성
  - 격자: `role="grid"` + `aria-label="네온 퓨즈 4×4 격자"`, 각 칸 `role="gridcell"`, 칩 칸 `aria-label="2행 3열, 값 16"`, 빈 칸 `aria-label="2행 3열, 빈 칸"`. 격자에 `tabindex="0"`, 포커스 시 방향키로 조작 가능 안내 `aria-describedby`.
  - 점수: 점수 영역 `aria-live="polite"`로 "점수 124, 4점 획득" 형태 알림(매 이동마다 하나로 묶어 1회).
  - 게임 오버: 별도 `role="alert"` 요소로 "게임 오버. 최종 점수 N점". 오버레이 열리면 "다시 하기" 버튼으로 포커스 이동.
  - 모든 버튼·링크 최소 44×44px, `:focus-visible`에 2px `--neon-cyan` 외곽선 + 2px 간격.

## 5. 파일 구조
```
apps/neon-fuse/
├── spec.md      이 계획서
├── index.html   마크업, Gaegu 글꼴 링크, 스크립트 로드(type="module")
├── style.css    :root 변수, 레이아웃, 칩 단계별 스타일, 반응형, reduced-motion
├── logic.js     DOM 없는 순수 게임 로직(export)
└── main.js      DOM 렌더링, 입력 처리, 저장, aria-live 알림
```
- 블로그의 `css/`, `js/`는 import하지 않음(필요한 색·글꼴 값은 복사).

### logic.js (순수 함수, 입력 배열을 변경하지 않고 새 값을 반환)
- `createEmptyBoard()` → 4×4 0 배열
- `slideLine(line)` → `{ line, gained, merged: boolean[] }` 한 줄을 앞쪽으로 밀고 합침
- `move(board, dir)` → `{ board, gained, moved, mergedCells }` dir: `'up'|'down'|'left'|'right'`
- `emptyCells(board)` → `[ [r, c], ... ]`
- `addRandomTile(board, rng = Math.random)` → 새 보드(2 90% / 4 10%)
- `canMove(board)` → 빈 칸 또는 이웃한 같은 값이 있으면 true
- `newGame(rng)` → 타일 2개가 놓인 보드
- `maxLevel(board)` → 가장 높은 Lv
- rng를 주입받아 테스트에서 결과를 고정할 수 있게 함.

### main.js
- `init()`, `render(state)`, `handleDirection(dir)`, `bindKeyboard()`, `bindSwipe(el)`, `showGameOver()`, `hideGameOver()`, `announce(msg)`, `showToast(msg)`, `loadBest()`, `saveBest(n)`.

## 6. 저장
- `localStorage` 키: `neon-fuse:best` (정수 문자열). 읽기·쓰기 모두 try/catch, 실패하면 최고 점수 0으로 시작하고 저장은 조용히 건너뜀. 진행 중인 판은 저장하지 않음.
